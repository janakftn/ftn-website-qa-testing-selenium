# ftn-website-qa-testing-selenium
# Testiranje FTN veb-sajta – QA projekat

## O projektu
Projekat obuhvata automatizovano testiranje veb-sajta Fakulteta tehničkih nauka u Novom Sadu (https://ftn.uns.ac.rs/).

Cilj projekta je provera funkcionalnosti navigacije i pretrage na veb-sajtu korišćenjem alata za automatizovano testiranje.

## Korišćene tehnologije
- Python
- Selenium WebDriver
- Pytest
- pytest-html

## Obim testiranja
Kreirano je ukupno 10 zasebnih test slučajeva koji obuhvataju:

- Navigaciju kroz veb-sajt
- Funkcionalnost pretrage
- Pozitivne i negativne test scenarije
- Pretragu sa praznim unosom
- Pretragu sa specijalnim karakterima i razmacima
- Testiranje graničnih vrednosti

## Izveštaj o testiranju
Izveštaj o izvršavanju testova generisan je pomoću alata pytest-html.

Fajl: `report.html`
